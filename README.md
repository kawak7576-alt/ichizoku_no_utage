# 一族の宴 ― 消えた家宝と変装者 ―

5人オンライン対戦型・正体隠匿 × ワードウルフ推理ゲーム。
スマートフォン・PC両対応、ゲームマスター不要、URL共有だけで参加可能。

---

## 🎯 開発目的・ゲーム概要
- **人数**: 5人固定
- **目標プレイ時間**: 約15分
- **対応環境**: スマートフォン、タブレット、PC（レスポンシブ）
- **言語**: 日本語
- **秘密情報管理**: 役職・ワード・指定ワードなどの情報はサーバー側で厳格に管理され、権限のある本人にのみ送信されます。

---

## 🏰 世界観とルール
裕福な一族の屋敷で祖父の誕生日会の最中、大切な家宝が盗まれた。
怪盗は一族の誰かに変装し、「ボクは誰かに変装している、探し出してみなヨ」と告げる。

### 役職カード（計6枚）
1. **学生 (3枚)**: 一族側。正または誤のワードを受け取る。
2. **秀才 (1枚)**: 一族側。必ず【正のワード】を受け取る。
3. **怪盗 (1枚)**: 怪盗側。必ず【誤のワード】を受け取る。最多得票で指名された場合、救済回答が可能。
4. **妖狐 (1枚)**: 妖狐側。必ず【正のワード】を受け取る。指定ワードを会話中に発言し、怪しまれずに逃げ切れば単独勝利。

### キャラクター・担当場所（全6種）
- 長男（書斎）
- 長女（ギャラリー）
- 次男（エントランス）
- 次女（庭園）
- 三男（食堂）
- 三女（遊戯室）
※選ばれなかった1人は「療養室で寝込んでいる人物」となります（投票対象）。

## 🚀 ローカル起動手順

### 1. 依存関係のインストール
```bash
npm install
```

### 2. 開発サーバーの起動
```bash
npm run dev
```
起動後、ブラウザで `http://localhost:3000` を開きます。

### 3. 本番ビルド & 起動
```bash
npm run build
npm start
```
